# Changelog

## 1.0.0 — 3 October 2026

- First release. Settings for the journal and its Crossref login (the password stored encrypted with the site's own
  keys); a "Crossref record" box on each article (authors with ORCID iDs and affiliations with ROR IDs, abstract,
  volume, issue, pages, references, licence, full-text PDF); Crossref → Records, with each article's file, what the
  record carries and still lacks, and the verdict of Crossref's 5.4.0 schema before anything is sent; Deposit, Crossref's
  result, and the read-back from Crossref's REST API; on registered articles the DOI link, the citation tags and
  Crossref's Crossmark button. The record is completed by the same core as Complete Records for Crossref for OJS 1.0.0.5.
  Tested on WordPress 7.1.2.
